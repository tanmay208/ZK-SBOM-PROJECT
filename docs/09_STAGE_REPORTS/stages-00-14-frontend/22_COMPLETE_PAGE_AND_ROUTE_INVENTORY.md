# Complete Page and Route Inventory

Date: 2026-10-01
Stage: 3 — Complete Product Requirements, Page Inventory & User Flow Freeze

## Public Pages

### 1. Login (`/login`)
- **Purpose:** User authentication.
- **Auth:** Public.
- **Allowed Roles:** Any (unauthenticated).
- **API Dependencies:** `POST /api/v1/auth/login`.
- **Primary Actions:** Submit credentials.
- **Navigation Entry:** None (redirects here if unauthenticated).
- **Direct URL Behavior:** Loads form. Redirects to `/dashboard` if already authenticated.
- **States:** Idle, Submitting, Success (redirect), Error (invalid credentials).

### 2. Registration (`/register`)
- **Purpose:** User account creation.
- **Auth:** Public.
- **Allowed Roles:** Any (unauthenticated).
- **API Dependencies:** `POST /api/v1/auth/register`.
- **Primary Actions:** Submit new credentials.
- **Navigation Entry:** Link from Login page.
- **Direct URL Behavior:** Loads form. Redirects to `/dashboard` if already authenticated.
- **States:** Idle, Submitting, Success (redirect to login), Error (conflict, validation).

### 3. Public Certificate View (`/certificates/[id]`)
- **Purpose:** Publicly verifiable cryptographic certificate display.
- **Auth:** Public.
- **Allowed Roles:** Any.
- **API Dependencies:** `GET /api/v1/verification/certificates/{id}`.
- **Primary Actions:** View metadata.
- **Navigation Entry:** None (accessed via direct link/UUID).
- **Direct URL Behavior:** Loads certificate.
- **States:** Loading, Success (certificate display), Error (404 Not Found), Error (network).

## Authenticated Shared Pages

### 4. Dashboard (`/dashboard`)
- **Purpose:** High-level metrics overview.
- **Auth:** Authenticated.
- **Allowed Roles:** Any (`vendor`, `admin`, `auditor`).
- **API Dependencies:** `GET /api/v1/auth/me`, `GET /api/v1/metrics`.
- **Primary Actions:** Navigate to specific sections.
- **Navigation Entry:** Top-level / Main Menu.
- **Direct URL Behavior:** Loads dashboard. Redirects to `/login` if unauthenticated.
- **States:** Loading, Success (metrics display), Error (401 -> redirect).

### 5. Verification Interface (`/verify`)
- **Purpose:** Form to submit proof artifacts and public inputs for cryptographic verification.
- **Auth:** Authenticated.
- **Allowed Roles:** Any.
- **API Dependencies:** `POST /api/v1/verification/verify`, `GET /api/v1/vulnerability/snapshots`, `GET /api/v1/policy`.
- **Primary Actions:** Submit proof.
- **Secondary Actions:** Select active policy/snapshot to prefill inputs.
- **Navigation Entry:** Main Menu.
- **States:** Idle, Submitting, Success (Verified + Cert), Success (Invalid/Mismatch), Error (422, network).

### 6. Certificate Directory (`/certificates`)
- **Purpose:** List of certificates generated by the system.
- **Auth:** Authenticated.
- **Allowed Roles:** Any.
- **API Dependencies:** `GET /api/v1/verification/certificates`.
- **Primary Actions:** Paginate, click through to Certificate View.
- **Navigation Entry:** Main Menu.
- **States:** Loading, Empty, Success (list), Error.

## Vendor/Admin Pages (Proof Generation)

### 7. SBOM Management (`/sboms`)
- **Purpose:** List user's uploaded SBOMs.
- **Auth:** Authenticated.
- **Allowed Roles:** `vendor`, `admin`.
- **Owner-Only:** Yes (user-scoped by API).
- **API Dependencies:** `GET /api/v1/sbom`.
- **Primary Actions:** Paginate, navigate to Upload.
- **Navigation Entry:** Main Menu (hidden from auditors).
- **Forbidden Behavior:** 403 / UI block for `auditor`.
- **States:** Loading, Empty, Success (list), Error.

### 8. SBOM Upload (`/sboms/upload`)
- **Purpose:** Submit a new SBOM JSON.
- **Auth:** Authenticated.
- **Allowed Roles:** `vendor`, `admin`.
- **API Dependencies:** `POST /api/v1/sbom/upload`.
- **Primary Actions:** Select file, fill application metadata, submit.
- **States:** Idle, Validating, Submitting, Success (redirect to list), Error (422, 413, 403).

### 9. Proof Jobs Directory (`/proofs`)
- **Purpose:** List user's ZKP generation jobs.
- **Auth:** Authenticated.
- **Allowed Roles:** `vendor`, `admin`.
- **Owner-Only:** Yes (user-scoped by API).
- **API Dependencies:** `GET /api/v1/zkp`.
- **Primary Actions:** Paginate, navigate to job detail, navigate to Generate.
- **Navigation Entry:** Main Menu (hidden from auditors).
- **States:** Loading, Empty, Success (list), Error.

### 10. Generate Proof (`/proofs/generate`)
- **Purpose:** Form to request a new proof.
- **Auth:** Authenticated.
- **Allowed Roles:** `vendor`, `admin`.
- **API Dependencies:** `GET /api/v1/sbom`, `GET /api/v1/vulnerability/snapshots`, `GET /api/v1/policy`, `POST /api/v1/zkp/generate`.
- **Primary Actions:** Select SBOM, snapshot, policy, submit.
- **States:** Loading dependencies, Idle, Submitting, Success (redirect to job detail), Error.

### 11. Proof Job Detail (`/proofs/[id]`)
- **Purpose:** View status, public inputs, and download proof artifact.
- **Auth:** Authenticated.
- **Allowed Roles:** `vendor`, `admin`.
- **Owner-Only:** Yes (user-scoped by API).
- **API Dependencies:** `GET /api/v1/zkp/jobs/{id}`.
- **Primary Actions:** Copy proof artifact, copy roots.
- **States:** Loading, Success (pending/running), Success (completed), Success (failed), Error (404, 403).

## Admin Pages

### 12. Policy Management (`/admin/policies`)
- **Purpose:** View and create security policies.
- **Auth:** Authenticated.
- **Allowed Roles:** View: Any / Create: `admin`.
- **API Dependencies:** `GET /api/v1/policy`, `POST /api/v1/policy`.
- **Primary Actions:** View list, submit new policy.
- **Navigation Entry:** Main Menu (Create controls restricted to admin).
- **States:** Loading, Empty, Success (list), Submitting new, Error.

### 13. Vulnerability Intelligence (`/admin/vulnerabilities`)
- **Purpose:** View snapshots, ingest new data, approve/revoke snapshots.
- **Auth:** Authenticated.
- **Allowed Roles:** View: Any / Modify: `admin`.
- **API Dependencies:** `GET /api/v1/vulnerability/snapshots`, `POST /api/v1/vulnerability/ingest`, `POST /approve`, `POST /revoke`.
- **Primary Actions:** View list, ingest JSON, approve, revoke.
- **Navigation Entry:** Main Menu (Modify controls restricted to admin).
- **States:** Loading, Empty, Success (list), Submitting ingest, Updating status, Error.

## System Pages
- **404 Not Found:** Default fallback for unknown routes.
- **403 Forbidden:** Displayed when navigating directly to a role-restricted route without permission.
